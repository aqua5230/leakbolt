# 安裝方式與平台決策（2026-08-29，證據見 04 / 05）

## 一、hook 安裝：不能靠全域 core.hooksPath

事實（05 節 2，原始碼已核）：
- `core.hooksPath` 是單一值，設了就完全取代 `.git/hooks`，不合併。
- husky v9 安裝時必定執行 `git config core.hooksPath .husky/_`（repo 層級），會蓋掉我們的全域設定。
- lefthook 與 pre-commit（Python）偵測到 `core.hooksPath` 已設定時直接拒裝報錯。

推論：
1. 「設全域 hooksPath 一次搞定」不成立——任何裝 husky 的 repo 都會蓋掉它。
2. 更嚴重的是反向傷害：我們若設了全域 `core.hooksPath`，會害使用者之後裝不了 lefthook 與 pre-commit。不可接受。

決定：`leakbolt install` 走偵測式 per-repo 安裝——
- 無 hook 管理工具 → 寫 `.git/hooks/pre-commit`（本機檔，不進版控，不影響隊友）
- 有 husky → 追加到 `.husky/pre-commit`
- 有 lefthook / pre-commit → 寫進它們的設定檔
- 全域 `core.hooksPath` 只做進階選項，安裝前必檢查是否已被佔用，被佔用就不動。

**四個分支裡有三個寫進版控檔**（`.husky/pre-commit`、`lefthook.yml`、`.pre-commit-config.yaml`）。
這些檔會被 commit、傳給沒裝 leakbolt 的隊友，他們 commit 會直接失敗（`leakbolt: command not found`，
`sh` 找不到指令回 exit 127，非 0 就中止 commit）——這正是我們拒絕全域 hooksPath 的同一種「壞鄰居」。

所以寫進版控檔的那行一律帶存在性守衛：

    command -v leakbolt >/dev/null 2>&1 || exit 0
    leakbolt scan --staged || exit 1

沒裝的人靜默跳過，裝了的人才擋。安裝時要明白告訴使用者「這行會進版控、隊友看得到」，
並提供 `--local-only` 改用 `.git/hooks/pre-commit`（不進版控）。

## 一之二、install 必須含一次全歷史掃描

pre-commit hook 只擋「未來的 commit」。舊 commit 裡已經有的 key，每次 pre-commit 都會通過——
這正是 03 報告裡最強的證據（@Nqspq 量過 25 個 repo，現況乾淨但 history 有 key）。

決定：`leakbolt install` 掛完 hook 後**強制跑一次** `leakbolt scan --history`，
把結果當安裝報告直接秀出來。history 髒的話當場告訴使用者「這些 key 已經在歷史裡，
刪檔案沒有用，必須作廢」，並導向引導式止血流程。跳過這步的話，
使用者裝完會得到一個「我已經安全了」的錯誤感覺——那是 DECISION.md 三件不能忍的第 2 條。

桌面版的「零設定」＝掃描本機所有 git repo、一鍵批次安裝＋批次歷史掃描，不是靠全域 hooksPath 硬幹。

## 二、平台

- gitleaks v8.30.1（2026-03-21）官方有 windows_x64 / windows_arm64 / linux / darwin 二進位（`gh` 核過）。
  **引擎**跨平台零成本；**hook 腳本**不是——`.git/hooks/pre-commit` 是 shell script，
  Windows 上靠 Git for Windows 內附的 Git Bash 執行，不附 Git Bash 的 GUI 客戶端會失效。列為已知限制。
- 開發者 OS（Stack Overflow 2025 專業使用）：Windows 49.5%、macOS 32.9%、Ubuntu 27.7%、WSL 16.8%。
- Cursor / Claude Code / Lovable / Replit 都有原生 Windows；v0 純瀏覽器。
- 簽章年費：macOS Apple Developer $99/年（公證不另收）；Windows OV $129~$313/年、EV $349~$411/年，另 2023-06 起強制硬體金鑰，首年加 $90~$379。

決定：
- 免費 CLI 第一天支援 macOS / Windows / Linux（CLI 不用簽章，砍 Windows 等於砍掉近半散播面）。
- 付費桌面 GUI 先只做 macOS，Windows 版等需求出現再付簽章成本。
- 核心引擎用單一可攜執行檔（Go／Rust）寫，介面殼才用平台原生，避免邏輯綁死 macOS。
