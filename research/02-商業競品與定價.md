# 商業競品與開源市場分析報告（API Key / 密鑰防洩）

## 1. 商業競品

### GitGuardian
- **URL**：https://www.gitguardian.com/pricing
- **定位一句話**：專注於軟體開發生命週期（SDLC）全流程的即時密鑰偵測、事件修復與代碼安全治理平台。
- **免費額度**：Free 方案支援最多 25 位貢獻開發者（contributing developers），每月提供 10,000 次 API 掃描配額，包含本機 CLI（ggshield）與 pre-commit hooks。
- **付費起價**：Business 方案採客製報價（AWS Marketplace 參考價為 25 位開發者每年約 $5,500 美元，約合 $458.33 美元/月；官方價格頁查無公開單月起價）。
- **主打客戶**：企業（以中大型研發團隊與企業資安團隊為主，並以 Free 方案覆蓋小型團隊）。

### Truffle Security（TruffleHog 商業版）
- **URL**：https://trufflesecurity.com/pricing
- **定位一句話**：主打即時動態驗證（Live Verification）並整合企業多源資料（SaaS、雲端、Slack、Jira 等）的憑證外洩防護平台。
- **免費額度**：開源版 TruffleHog CLI 完全免費（支援 800+ 種驗證偵測器）；商業 Enterprise 方案無永久免費額度（僅提供 Demo 與洽詢試用）。
- **付費起價**：Enterprise 方案為客製報價（價格頁查無公開月費價格，需聯繫業務按掃描範圍與授權單位客製合約）。
- **主打客戶**：企業（以具備跨系統資安合規需求的中大型企業與 DevSecOps 團隊為主）。

### Doppler
- **URL**：https://www.doppler.com/pricing
- **定位一句話**：提供跨環境、跨雲端集中式機密資訊與環境變數管理（Secrets Management）及自動同步與輪換平台。
- **免費額度**：Developer 方案提供前 3 位使用者永久免費（Free for 3 users），包含 Doppler CLI、服務 Token、3 天活動日誌、5 個 Config Syncs。
- **付費起價**：Developer 方案第 4 位使用者起為 $8 美元/人/月（$8/user/month）；Team 方案為 $21 美元/人/月（$21/user/month）。
- **主打客戶**：企業與中小型工程團隊（提供 3 人以內個人/小型專案免費使用）。

### Infisical
- **URL**：https://infisical.com/pricing
- **定位一句話**：端到端開源機密管理平台（Secrets Management），支援多環境變數同步、動態密鑰生成與外洩掃描。
- **免費額度**：Free 方案提供 5 個身分額度（5 identities，含人類使用者與機器/CI 身分）、無限制 projects、100+ integrations；開源核心版可免費自託管。
- **付費起價**：Pro 方案為 $20 美元/identity/月（年繳方案；月繳方案為 $23 美元/identity/月）。
- **主打客戶**：企業與工程團隊（適合需要多雲機密同步、自託管與身分控管的開發團隊）。

### 1Password Developer
- **URL**：https://developer.1password.com （定價頁：https://1password.com/pricing ）
- **定位一句話**：將成熟密碼庫生態延伸至開發者工作流程的機密自動化（Secrets Automation）、SSH 金鑰託管與 CLI 工具。
- **免費額度**：無永久免費額度（提供 14 天免費試用）。
- **付費起價**：個人開發者若僅使用本地 CLI / SSH Agent，可使用 Individual 方案 $2.99 美元/月（年繳 $35.88 美元/年）；若需完整機密自動化與服務帳號（Secrets Automation / Service Accounts），付費起價為 Teams Starter Pack 方案 $24.95 美元/月（固定包含 10 人）或 Business 方案 $8.99 美元/人/月（年繳）。
- **主打客戶**：企業與團隊（以企業集中憑證與權限控管為主，個人方案提供基礎本地開發者工具支援）。

### GitHub Secret Scanning（含 Push Protection）
- **URL**：https://docs.github.com/en/code-security/secret-scanning/introduction/about-secret-scanning （定價頁：https://github.com/pricing ）
- **定位一句話**：GitHub 原生整合的代碼庫安全防護機制，於程式碼推送時即時攔截（Push Protection）或在儲存庫中主動掃描外洩憑證。
- **免費額度**：所有公開儲存庫（Public Repositories）以及所有個人帳號對公開庫的 Push Protection 完全免費且預設啟用。
- **付費起價**：私有儲存庫（Private Repositories）需付費，GitHub Secret Protection 獨立方案為 $19 美元/活躍提交者/月（$19/active committer/month），或透過完整 GitHub Advanced Security（GHAS）套裝約 $49 美元/活躍提交者/月。
- **主打客戶**：企業與組織（私有儲存庫與進階規則客戶），同時以免費機制保護廣大開源社群。

## 2. GitHub 官方 Push Protection 現況與限制

### 免費開放程度
- **公開儲存庫（Public Repositories）**：完全免費且預設啟用。無論是個人帳號還是組織帳號擁有的公開 repo，任何使用者推送代碼時若包含受支援的密鑰格式，均會被 Push Protection 自動阻擋。
- **個人帳號（Personal Accounts）**：個人帳號設定中內建「Push protection for yourself」（預設開啟），但該免費防護**僅在推送到公開 repo 時生效**。
- **私有儲存庫（Private Repositories）**：**不提供免費開放**。個人或組織的私有儲存庫若要啟用 Push Protection，必須付費購買 GitHub Secret Protection（$19 美元/活躍提交者/月）或 GHAS 授權。

### 明顯限制
1. **防護邊界限制於 Git Push 階段**：Push Protection 僅在執行 `git push` 到 GitHub 遠端伺服器時進行檢查。它無法防護本機未推送的檔案（例如本機暫存的 `.env`）、無法阻止 AI 開發工具（如 Cursor、Windsurf、Claude）直接讀取本機代碼上下文，亦無法防範開發者直接在 AI 聊天視窗中貼上金鑰。
2. **偵測規則庫受限於合作夥伴特徵（Signature）**：免費版 Push Protection 僅比對 GitHub Secret Scanning Partner Program（約 200+ 家合作廠商，如 AWS、OpenAI、Slack 等）發行的標準格式 Token。使用者若要自訂正則規則（Custom Patterns），必須升級至企業版 GHAS / Secret Protection。
3. **阻擋容易被開發者自行繞過（Bypass）**：推送被攔截時，終端機會直接提供一組 Bypass URL，開發者只要點擊並勾選「這是測試用金鑰」或「我稍後修復」即可強制推送上傳。在未開啟進階安全監控的公開 repo 上，繞過行為甚至不會產生後續審計警報。
4. **動態有效性驗證覆蓋不完全**：僅部分主流廠商的 Token 支援推送當下的即時有效性檢查（Validity Check），其餘多數仍依賴格式匹配，存在誤報或無法判斷已失效金鑰的狀況。

## 3. 開源競品

### TruffleHog
- **URL**：https://github.com/trufflesecurity/trufflehog
- **Star 數**：27,623 stars
- **與 Gitleaks 差異一句話**：主打「動態聯網驗證（Live Validation）」，即時呼叫 800+ 種服務 API 檢測金鑰是否仍然有效以大幅降低誤報，但掃描速度較慢且必須聯網；而 Gitleaks 專注於極速、純本機離線的靜態正則與熵值掃描。

### detect-secrets（Yelp）
- **URL**：https://github.com/Yelp/detect-secrets
- **Star 數**：4,630 stars
- **與 Gitleaks 差異一句話**：以 Python 開發並核心導入「基準檔（Baseline）」機制，專為既有大型程式庫循序漸進消除舊密鑰與例外管理而設計；而 Gitleaks 是以 Go 編寫的單一二進位檔，無執行環境依賴且掃描效能更高。

### ggshield（GitGuardian CLI）
- **URL**：https://github.com/GitGuardian/ggshield
- **Star 數**：1,994 stars
- **與 Gitleaks 差異一句話**：本質為 GitGuardian 商業 SaaS 平台的本地端 CLI 與 pre-commit 前端工具，依賴雲端 API 引擎與帳號額度進行分析；而 Gitleaks 為 100% 獨立開源、無須註冊任何雲端服務的離線工具。

### talisman（ThoughtWorks）
- **URL**：https://github.com/thoughtworks/talisman
- **Star 數**：2,096 stars
- **與 Gitleaks 差異一句話**：專門作為本機 Git Hook（pre-commit / pre-push）設計，除正則外還攔截敏感副檔名（如 `.pem`、`.key`）與大檔案，但規則庫更新停滯且功能局限於 Git Hook，生態與彈性遠不及 Gitleaks。

## 4. 缺口與缺口判斷

### 專為非專業工程師 / Vibe Coder 設計之產品（< $10/月、零設定、GUI）
**查無**

### 缺口判斷
目前市場上所有主流密鑰防洩產品（如 GitGuardian、TruffleHog、Doppler）皆嚴格面向具備資安基礎的專業工程師與企業團隊，高度依賴 CLI 指令、Git Hook、CI/CD 流水線或複雜的權限架構。新興的 AI 輔助開發者（Vibe Coders）與非專業開發者普遍缺乏終端機操作習慣與 Git 深度防護觀念，且極易在 AI 提示詞、本機 `.env` 或前端代碼中無意暴露出 API 金鑰。市面上雖然有零星免費的 VS Code 擴充套件，但缺乏「開箱即用、零設定、獨立 GUI 桌面端/背景守護、定價低於 10 美元/月」的平民化商業產品。這導致 Vibe Coder 族群在 AI 快速生成與部署專案時處於完全無防護的真空狀態，形成明顯且尚未被滿足的消費級/個人開發者市場缺口。
