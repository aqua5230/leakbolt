### 原始查詢回傳 NONE 原因分析
使用者執行 `gh repo view <repo> --json licenseInfo --jq .licenseInfo.spdxId` 回傳 NONE，係因 `gh repo view --json licenseInfo` 輸出之 JSON schema 僅含 `key`、`name` 與 `nickname` 欄位（例如 `{"licenseInfo":{"key":"mit","name":"MIT License","nickname":""}}`），並無 `spdxId` 欄位；若改用 `.licenseInfo.key` 或改用 REST API `gh api repos/<owner>/<repo> --jq .license.spdx_id` 即可正常取得識別碼。原始報告 `research/11` 所記錄之授權全數正確無誤。

## 自我審查抽查紀錄

隨機抽取 3 個專案使用方法 A（`gh api repos/<owner>/<repo> --jq '.license.spdx_id, .license.name'`）獨立重跑驗證：

```bash
# 抽查 1: adbar/trafilatura
$ gh api repos/adbar/trafilatura --jq '{spdx_id: .license.spdx_id, name: .license.name}'
{"name":"Apache License 2.0","spdx_id":"Apache-2.0"}
-> 驗證結果：一致（Apache-2.0）

# 抽查 2: sqldef/sqldef
$ gh api repos/sqldef/sqldef --jq '{spdx_id: .license.spdx_id, name: .license.name}'
{"name":"Other","spdx_id":"NOASSERTION"}
-> 驗證結果：一致（Other / NOASSERTION）

# 抽查 3: stripe/pg-schema-diff
$ gh api repos/stripe/pg-schema-diff --jq '{spdx_id: .license.spdx_id, name: .license.name}'
{"name":"MIT License","spdx_id":"MIT"}
-> 驗證結果：一致（MIT）
```
