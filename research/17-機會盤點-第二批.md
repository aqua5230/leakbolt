# 開源機會盤點：第二批外殼與 MCP 缺口

本報告針對 GitHub 上「底層技術成熟、但缺乏現代圖形介面（GUI）或尚未具備標準 MCP（Model Context Protocol）伺服器封裝」之開源專案進行第二輪客觀盤點。本批次聚焦於全新領域（電子書與文件處理、字幕與翻譯、3D 與 CAD、地理資訊、生物資訊與科學計算、財務與會計、遊戲資源處理、硬體與嵌入式、網路除錯與封包分析），排除第一批已列出之專案。所有指標數據均透過 GitHub CLI（`gh`）完成即時查證，不含主觀商業預測。

---

## 盤點標準與篩選條件

- **星數區間**：800 ～ 8,000 顆星（已獲社群驗證，具備穩定性但尚未飽和）
- **活躍度**：最近一年內（2025-08-29 至 2026-08-29）有 commit 推送紀錄（`pushed_at`）
- **領域限制**：涵蓋電子書/文件、翻譯/字幕、3D/CAD、GIS 圖資、生物資訊、財務會計、遊戲資源、嵌入式硬體、網路除錯等全新領域
- **查證依據**：
  - 基本數據：`gh api repos/<owner>/<repo> --jq '.stargazers_count, .pushed_at, .license.spdx_id'`
  - 公式① 介面缺口：官方 README/文檔檢視 ＋ `gh search repos "<專案名> gui"` 搜尋第三方 GUI 現況
  - 公式② MCP 缺口：`gh search repos "<專案名> mcp"` 搜尋既有 MCP Server 封裝現況
