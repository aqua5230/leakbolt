# git-secrets

1. 它的 pre-commit hook 找不到自己的執行檔時，是擋下 commit 還是放行？
擋下 commit。`git secrets --install` 在 hook 腳本中直接呼叫 `git secrets --pre_commit_hook -- "$@"`。當系統未安裝 `git-secrets`（不在 PATH 中）時，Git 執行子命令失敗並以非 0 狀態碼（exit code 1）退出，導致 pre-commit hook 失敗並擋下 commit。
程式碼片段（來源：`git-secrets`）：
```bash
  echo "#!/usr/bin/env bash" > "${dest}"
  echo "git secrets --${cmd} -- \"\$@\"" >> "${dest}"
  chmod +x "${dest}"
```
來源 URL：https://github.com/awslabs/git-secrets/blob/master/git-secrets （HTTP 200）

2. 有沒有「安裝狀態自我檢查」的指令？
查無資料（僅提供 `--list` 查詢 regex 設定，無 doctor/verify/status 等 hook 狀態自檢指令）。
來源 URL：https://github.com/awslabs/git-secrets/blob/master/README.rst （HTTP 200）

3. 有沒有專門處理「hook 進版控、隊友沒裝這個工具」的情況？怎麼處理的？
查無資料（git-secrets 僅將 hook 寫入本地 `.git/hooks/` 或 git template，不處理 hook 進版控時缺工具的容錯或引導）。
來源 URL：https://github.com/awslabs/git-secrets/blob/master/git-secrets （HTTP 200）

# talisman

1. 它的 pre-commit hook 找不到自己的執行檔時，是擋下 commit 還是放行？
擋下 commit（原生 hook 模式）。Talisman 的原生 hook 腳本直接執行 `${TALISMAN_BINARY}`，若執行檔不存在，Bash 執行失敗返回 exit code 127，Git 擋下 commit。
程式碼片段（來源：`global_install_scripts/talisman_hook_script.bash`）：
```bash
CMD="${TALISMAN_BINARY} ${DEBUG_OPTS} --githook ${HOOKNAME} ${INTERACTIVE}"
echo_debug "ARGS are $@"
echo_debug "Executing: ${CMD}"
${CMD}
```
來源 URL：https://github.com/thoughtworks/talisman/blob/main/global_install_scripts/talisman_hook_script.bash （HTTP 200）

2. 有沒有「安裝狀態自我檢查」的指令？
查無資料（CLI 選項僅包含 `-c/--checksum`、`-g/--githook`、`-s/--scan`、`-w/--scanWithHtml` 等，無 doctor/verify/status 等 hook 狀態自檢指令）。
來源 URL：https://github.com/thoughtworks/talisman/blob/main/README.md （HTTP 200）

3. 有沒有專門處理「hook 進版控、隊友沒裝這個工具」的情況？怎麼處理的？
有專門處理。在配合 pre-commit 框架時，官方提供的 hook 定義會在 entry 中檢查 `TALISMAN_HOME` 是否存在；若隊友未安裝/未設定環境變數，則印出提示訊息並放行 commit（exit code 0）。
腳本片段（來源：`global_install_scripts/install.bash`）：
```bash
-   repo: local
    hooks:
    -   id: talisman-precommit
        name: talisman
        entry: bash -c 'if [ -n "\${TALISMAN_HOME:-}" ]; then \${TALISMAN_HOME}/talisman_hook_script pre-commit; else echo "TALISMAN does not exist. Consider installing from https://github.com/thoughtworks/talisman . If you already have talisman installed, please ensure TALISMAN_HOME variable is set to where talisman_hook_script resides, for example, TALISMAN_HOME=\${HOME}/.talisman/bin"; fi'
        language: system
        pass_filenames: false
        types: [text]
        verbose: true
```
來源 URL：https://github.com/thoughtworks/talisman/blob/main/global_install_scripts/install.bash （HTTP 200）

# detect-secrets

1. 它的 pre-commit hook 找不到自己的執行檔時，是擋下 commit 還是放行？
擋下 commit。detect-secrets 官方透過 pre-commit 框架整合（提供 `.pre-commit-hooks.yaml`，指定 `entry: detect-secrets-hook`、`language: python`）。若執行檔不存在或環境建置失敗，pre-commit 框架以非 0 狀態碼退出並擋下 commit；若在原生 git hook 腳本中直接呼叫 `detect-secrets-hook`，找不到執行檔時 shell 返回 exit code 127 亦會擋下 commit。
程式碼片段（來源：`.pre-commit-hooks.yaml`）：
```yaml
-   id: detect-secrets
    name: Detect secrets
    description: Detects high entropy strings that are likely to be passwords.
    entry: detect-secrets-hook
    language: python
    # for backward compatibility
    files: .*
```
來源 URL：https://github.com/Yelp/detect-secrets/blob/master/.pre-commit-hooks.yaml （HTTP 200）

來源 URL：https://github.com/Yelp/detect-secrets/blob/master/detect_secrets/main.py （HTTP 200）

3. 有沒有專門處理「hook 進版控、隊友沒裝這個工具」的情況？怎麼處理的？
查無資料（detect-secrets 本身未提供 hook 層級的缺工具降級或略過機制，完全依賴 pre-commit 框架依 `.pre-commit-config.yaml` 宣告自動下載與建置虛擬環境）。

# trufflehog

1. 它的 pre-commit hook 找不到自己的執行檔時，是擋下 commit 還是放行？
擋下 commit。TruffleHog 官方推薦的原生 pre-commit hook 腳本直接執行 `trufflehog git ...`。當系統未安裝 trufflehog 時，shell 報錯（command not found，exit code 127），Git 收到非 0 狀態碼因而擋下 commit；若使用 pre-commit 框架（`language: system`），找不到執行檔同樣會由框架返回非 0 狀態碼並擋下 commit。
腳本片段（來源：`PreCommit.md`）：
```bash
#!/bin/sh
export TRUFFLEHOG_PRE_COMMIT=1
trufflehog git file://.
```
來源 URL：https://github.com/trufflesecurity/trufflehog/blob/main/PreCommit.md （HTTP 200）

2. 有沒有「安裝狀態自我檢查」的指令？
查無資料（CLI 包含 `git`、`filesystem`、`s3` 等掃描子指令及 `analyze`，無 doctor/verify/status 等 hook 狀態自檢指令）。
來源 URL：https://github.com/trufflesecurity/trufflehog/blob/main/README.md （HTTP 200）

3. 有沒有專門處理「hook 進版控、隊友沒裝這個工具」的情況？怎麼處理的？
查無資料（TruffleHog 官方文件將安裝 TruffleHog 列為前提條件 Prerequisites，未在 hook 腳本中提供隊友未安裝時的降級、略過或自動處理機制）。
來源 URL：https://github.com/trufflesecurity/trufflehog/blob/main/PreCommit.md （HTTP 200）
