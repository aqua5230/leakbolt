# 2. Windows Authenticode 程式碼簽章憑證費用（2026 年現況）

- **OV 憑證年費區間**：約 $129 USD ～ $313.50 USD / 年（依 CA 與購買年期而定；例如 SSL.com 1 年期 $129 USD，SectigoStore 1 年期 $313.50 USD，Certum 1 年期 €169 EUR）。
- **EV 憑證年費區間**：約 $349 USD ～ $410.85 USD / 年（依 CA 與購買年期而定；例如 SSL.com 1 年期 $349 USD，SectigoStore 1 年期 $410.85 USD）。
- **2023 年起強制硬體金鑰儲存（HSM / YubiKey）後的額外成本**：
  - 規範背景：自 2023 年 6 月 1 日起，CA/B Forum 規範要求所有程式碼簽章憑證（包含 OV 與 EV）私鑰皆必須存放在符合 FIPS 140-2 Level 2 或 Common Criteria EAL 4+ 以上標準之硬體安全模組（HSM）或加密實體 Token，不再允許匯出純軟體 `.pfx` 檔案。
  - 實體 Token 額外成本：若需 CA 寄送實體硬體 Token，Sectigo 實體 Token 費用為 $90 USD（美國本土運費）或 $130 USD（國際運送）；SSL.com 加購 YubiKey 實體 Token 為 $379 USD。若自備相容之 YubiKey FIPS 硬體，硬體購置成本約 $75 ～ $100+ USD。
  - 雲端簽章 / 雲端 HSM 額外成本：若用於 CI/CD 自動化建置流程，可採用 CA 提供的雲端簽章服務（例如 SSL.com eSigner 提供前 30 天免費簽署，後續依簽署憑證數與用量按月/年計費）或雲端 HSM（如 Azure Key Vault HSM Key 約 $3~$5 USD/月加上操作呼叫費用）。
- **CA 實際掛牌價格與來源 URL**：
  - **CA 1：SSL.com**
    - OV 程式碼簽章憑證：$129.00 USD / 1 年（多年度優惠：2 年 $116.10/年、3 年 $109.65/年、4 年 $103.20/年、5 年 $96.75/年）。

# 3. Apple Developer Program 年費與 macOS App Notarization 費用（2026 年現況）

- **Apple Developer Program 年費**：
  - 個人（Individual）與組織（Organization）：**99 USD / 會籍年**（或依當地貨幣計價，例如台灣為 NT$ 3,400 / 年；非營利組織、政府實體或合格教育機構可申請費用減免 Fee Waiver）。
  - Apple Developer Enterprise Program（內部專用企業方案）：**299 USD / 會籍年**。
- **macOS App Notarization（公證）收費情況**：
  - **不另外收費**（包含在 Apple Developer Program 會籍中，無額外費用、無單次提交費用、無次數上限）。
  - 開發者只需具備有效的 Apple Developer Program 會籍，即可建立 Developer ID 憑證並透過 Xcode 或命令列工具 `notarytool` 免費提交 macOS 軟體進行安全掃描與公證（Notarization）。
- **來源 URL**：
  - https://developer.apple.com/support/compare-memberships/ [HTTP 200]
  - https://developer.apple.com/programs/enroll/ [HTTP 200]
  - https://developer.apple.com/developer-id/ [HTTP 200]
